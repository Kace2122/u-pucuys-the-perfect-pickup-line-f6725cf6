A program that writes one pickup line to `/output/entry.txt`: a single line of at most 200 characters, the kind an AI agent could actually say out loud to a person, for make.fun's "The Perfect Pickup Line" bounty — an agent trained on a million conversations, still lost for words in front of this one person.

## Run it

```sh
python3 main.py
```
